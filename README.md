## About

Computer Science sophomore at **Southern Utah University**.

I build small tools that do one thing end to end, and I care more about
understanding why a design is right than about getting it working fast. Right
now that means AI-backed CLI tools in Python, and systems programming in C.

- 🔭 Building **[Study Buddy](https://github.com/projuan/study-buddy)** — active recall and spaced repetition, powered by the Claude API
- 🌱 Learning backend engineering through **boot.dev**, and C from **K&R**
- 🧰 Python · C · JavaScript · git · Anthropic API

### [Study Buddy](https://github.com/projuan/study-buddy)

A CLI that takes your notes and quizzes you on them. Claude extracts a
knowledge tree, writes a question per concept, and grades free-text answers;
**SM-2** decides what comes back and when.

Built the whole pipeline from scratch — structured outputs with Pydantic,
JSON persistence, and a scheduler that derives what's due from the data
instead of saving a position.
